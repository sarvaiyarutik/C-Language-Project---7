# 🖥️ C Menu-Driven Calculator

> A simple, interactive C program that performs basic arithmetic operations in a **loop until exit**.

---

## 🔹 Quick Info
- **Language:** C  
- **Type:** Console application  
- **Program Structure:** Functions (UDF), Switch-Case, Loops  
- **Author:** Rutik Sarvaiya  

---
Online GDB link : https://onlinegdb.com/w28uP_my9


## ⚡ Features
| Operation | Symbol | Notes |
|-----------|--------|-------|
| Addition | ➕ | Returns sum of two numbers |
| Subtraction | ➖ | Returns difference |
| Multiplication | ✖️ | Returns product |
| Division | ➗ | Integer division, handles division by zero |
| Modulus | 🧮 | Returns remainder |

- 🌀 Runs continuously until user exits  
- ⚠️ Handles division by zero gracefully  

---

## 📝 How It Works

1. Program shows a menu with options:
    ```
    1. Addition (+)
    2. Subtraction (-)
    3. Multiplication (*)
    4. Division (/)
    5. Modulus (%)
    0. Exit
    ```
2. User selects an operation (1-5)  
3. User enters two numbers  
4. Program outputs the result  
5. Menu repeats until user chooses 0
